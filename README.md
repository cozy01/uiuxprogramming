# BARRE - 운동 계획 서비스

## 사용자와 목표
- 사용자: 바레 운동을 시작하고 자신에게 맞는 운동을 탐색하는 성인
- 목표: 키와 몸무게로 BMI를 확인하고, 추천 BARRE 테마를 이해한 뒤 운동 계획을 설정한다.
- 주요 행동: BMI 계산 및 BARRE 테마 추천 결과를 확인하고 운동 목표와 조건을 설정한다.

## 9주차 신규 기능
9주차에는 사용자가 운동 계획을 더 쉽게 입력하고 제출할 수 있도록 입력 경험과 제출 상태 처리를 개선하였다.
- 운동 목표 입력 필드에 도움말과 글자 수 표시를 추가하였다.
- 운동 목표를 2자 이상 입력해야 다음 단계로 진행할 수 있도록 입력 조건을 적용하였다.
- 입력 도중 현재 글자 수와 조건 충족 여부를 실시간으로 표시하도록 구현하였다.
- 입력 조건을 충족하면 성공 상태를 표시하고, 조건을 충족하지 못하면 오류 문구를 표시하도록 구현하였다.
- 스트레칭 포함 여부에 따라 스트레칭 시간 선택 영역이 나타나거나 사라지도록 구현하였다.
- 스트레칭 시간 선택 영역이 숨겨질 때 내부 입력 요소를 비활성화하여 제출 데이터에서 제외되도록 처리하였다.
- 운동 계획 저장 과정에서 진행 상태를 표시하고 버튼을 비활성화하여 중복 제출을 방지하도록 구현하였다.
- 저장 성공 시 완료 메시지를 표시하도록 구현하였다.
- 저장 실패 시 입력 내용을 유지한 상태에서 다시 시도할 수 있도록 구현하였다.
- 다시 설정하기 기능 실행 시 운동 목표, 운동 조건, 오류 문구, 안내 문구, 제출 상태를 초기화하도록 개선하였다.

## 입력 조건

### 운동 목표
- 필수 입력 항목이다.
- 2자 이상 입력해야 한다.
- 최대 30자까지 입력할 수 있다.
- 현재 입력한 글자 수를 실시간으로 표시한다.

### 스트레칭 시간
- 스트레칭 포함을 선택한 경우에만 설정할 수 있다.
- 스트레칭 시간은 총 운동 시간보다 짧아야 한다.
- 스트레칭 포함을 해제하면 관련 입력 요소가 비활성화된다.

### 운동 계획 저장
- 저장 중에는 버튼이 비활성화된다.
- 저장이 완료되면 성공 메시지를 표시한다.
- 저장에 실패하면 입력 내용을 유지한 상태에서 다시 시도할 수 있다.

## 동작 확인 순서
- 개인정보 활용에 동의하고 계획 설정을 시작한다.
- 키와 몸무게를 입력하여 BMI를 계산한다.
- 추천 BARRE 테마를 확인한다.
- 운동 목표를 입력한다.
- 운동 목표 글자 수와 입력 상태가 실시간으로 갱신되는지 확인한다.
- 운동 목표를 비우거나 1글자만 입력했을 때 오류 문구가 표시되는지 확인한다.
- 스트레칭 포함 여부를 변경하여 스트레칭 시간 선택 영역이 표시되거나 숨겨지는지 확인한다.
- 운동 조건을 설정한 뒤 내용 확인 화면으로 이동한다.
- 운동 계획 저장 버튼을 눌러 저장 중 상태가 표시되는지 확인한다.
- 저장 완료 후 최종 운동 계획 요약 카드가 표시되는지 확인한다.
- URL에 ?save-error=1을 추가하여 저장 실패 메시지가 표시되는지 확인한다.
- 다시 설정하기 버튼을 눌러 운동 목표, 운동 조건, 안내 문구, 제출 상태가 초기화되는지 확인한다.

## 사용자 흐름
1. 개인정보 활용에 동의하고 '계획 설정 시작하기'를 누른다.
2. 개인정보 활용 안내를 확인한다. 취소 또는 Esc 시 동의가 해제된다.
3. 키와 몸무게를 입력하고 'BMI 계산하고 추천받기'를 누른다.
4. 잘못된 값은 같은 화면에서 오류를 확인하고 수정한다.
5. 올바른 값이면 BMI와 추천 BARRE 테마를 확인한다.
6. 여섯 가지 테마 소개 탭을 선택해 설명을 비교한다.
7. '추천 확인하고 계획 설정하기'를 눌러 BMI와 추천 테마 정보를 유지하면서 기존 운동 계획 설정을 진행한다.
8. 운동 목표, 운동 시간, 스트레칭을 설정하고 내용을 확인한다.
9. 운동 계획을 완료하면 BMI와 추천 테마를 포함한 최종 운동 계획 요약 카드를 확인한다.
10. '다시 설정하기'를 눌러 운동 계획을 다시 설정할 수 있다.

## 완료 조건
운동 계획 설정은 다음 조건을 모두 만족했을 때 완료된 것으로 판단한다.
- 개인정보 활용 동의 후 안내 팝업에서 '동의하고 설정 시작하기'를 선택한다.
- 키와 몸무게를 올바른 범위로 입력하여 BMI 계산을 완료한다.
- 추천 BARRE 테마를 확인한다.
- 운동 목표를 입력한다.
- 운동 시간을 선택한다.
- 스트레칭 시간이 총 운동 시간보다 짧도록 설정한다.
- 내용 확인 화면에서 입력한 내용을 검토한다.
- '운동 계획 저장하기' 버튼을 눌러 최종 운동 계획 요약 카드를 표시한다.
- '✓ 계획 설정 완료' 상태 메시지가 표시되면 운동 계획 설정이 완료된 것으로 판단한다.

## 인터랙션 시나리오

### 1. 개인정보 활용 동의
- 사용자가 개인정보 활용 동의 체크박스를 선택하면 '계획 설정 시작하기' 버튼이 활성화된다.
- 버튼을 누르면 개인정보 활용 안내 팝업이 표시된다.
- '돌아가기' 또는 Esc를 누르면 팝업이 닫히고 개인정보 활용 동의가 해제된다.
- '동의하고 설정 시작하기'를 누르면 BMI 입력 화면으로 이동한다.

### 2. BMI 계산 및 BARRE 테마 추천
- 사용자가 키와 몸무게를 입력하고 'BMI 계산하고 추천받기' 버튼을 누르면 입력값을 검사한다.
- 입력값이 비어 있거나 지정된 범위를 벗어나면 오류 메시지를 표시하고 해당 입력창으로 이동한다.
- 올바른 값을 입력하면 BMI를 계산하고 BMI 구간에 따른 추천 BARRE 테마와 추천 이유를 표시한다.
- 추천된 테마가 자동으로 선택되며, MOVE / BALANCE / CORE / CARDIO / BURN / SLOW 탭을 눌러 각 테마의 운동 강도와 설명을 비교할 수 있다.
- '다시 계산하기'를 누르면 입력값과 계산 결과가 초기화된다.
- '추천 확인하고 계획 설정하기'를 누르면 BMI와 추천 테마 정보만 유지하고 운동 계획 설정 화면을 표시한다.

### 3. 운동 목표 및 조건 설정
- 사용자가 운동 목표를 입력하고 '운동 조건 선택하기' 버튼을 누르면 입력값을 검사한다.
- 운동 목표가 비어 있으면 오류 메시지를 표시하고 다음 단계로 이동하지 않는다.
- 운동 시간을 선택하면 선택한 시간이 실시간으로 표시된다.
- 스트레칭 포함 여부를 선택하면 스트레칭 시간을 설정할 수 있다.
- 스트레칭 시간이 총 운동 시간 이상이면 오류 메시지를 표시하고 다음 단계로 이동하지 않는다.
- '내용 확인하기'를 누르면 운동 목표, 운동 시간, 스트레칭 설정 내용을 표시한다.
- '수정하기'를 누르면 이전 단계로 돌아가 운동 조건을 변경할 수 있다.

### 4. 최종 운동 계획 확인
- 사용자가 입력한 내용을 확인하고 '운동 계획 저장하기' 버튼을 누르면 최종 운동 계획 요약 카드를 표시한다.
- 최종 요약 카드에는 BMI, 추천 BARRE 테마, 운동 목표, 운동 시간, 스트레칭 정보가 표시된다.
- 계획 설정이 완료되면 진행 단계 대신 완료 상태를 표시한다.
- '다시 설정하기'를 누르면 운동 목표와 조건이 초기화되고 첫 번째 설정 단계로 돌아간다.
- BMI와 추천 BARRE 테마 정보는 유지하여 운동 계획을 다시 설정할 수 있다.

### 5. 기타 인터랙션
- 화면 테마 변경 버튼을 누르면 라이트 모드와 다크 모드가 전환된다.

## BMI 추천 규칙
- BMI < 18.5: SLOW
- 18.5 ≤ BMI < 23: CORE
- 23 ≤ BMI < 25: MOVE
- 25 ≤ BMI < 30: BALANCE
- BMI ≥ 30: SLOW

BMI는 참고 지표이며, BMI만으로 운동 능력이나 개인에게 적합한 운동 강도를 판단하지 않는다.

## 테스트 기록

### 1. 정상 경로
- BMI 23.9 계산 시 MOVE 테마가 추천되는 것을 확인하였다.
- BMI와 추천 테마 정보가 유지된 상태에서 운동 계획 설정 화면으로 이동하는 것을 확인하였다.
- 운동 목표 '체중감량', 운동 시간 30분, 스트레칭 10분을 설정한 뒤 최종 운동 계획 요약 카드에 입력 내용이 반영되는 것을 확인하였다.
- '운동 계획 저장하기' 버튼을 눌렀을 때 BMI, 추천 BARRE 테마, 운동 목표, 운동 시간, 스트레칭 정보가 최종 요약 카드에 정상적으로 표시되는 것을 확인하였다.
- 완료 단계 진입 시 진행 단계 표시가 숨겨지고 '✓ 계획 설정 완료' 상태 메시지가 표시되는 것을 확인하였다.

### 2. 오류 및 다른 경로
- 키 또는 몸무게를 입력하지 않았을 때 오류 메시지가 표시되는지 확인하였다.
- 키 또는 몸무게가 지정된 범위를 벗어났을 때 오류 메시지가 표시되는지 확인하였다.
- 잘못된 값을 수정한 뒤 정상적으로 BMI를 다시 계산할 수 있는지 확인하였다.
- 운동 목표를 입력하지 않았을 때 오류 메시지가 표시되고 다음 단계로 이동하지 않는 것을 확인하였다.
- 스트레칭 시간이 총 운동 시간 이상일 때 오류 메시지가 표시되고 다음 단계로 이동하지 않는지 확인하였다.
- 개인정보 활용 안내에서 '돌아가기' 또는 Esc를 눌렀을 때 동의가 해제되는지 확인하였다.

### 3. 수정 기능 테스트
- 운동 목표를 입력한 뒤 운동 조건 선택 화면으로 이동하는 것을 확인하였다.
- 운동 시간과 스트레칭 시간을 선택한 뒤 내용 확인 화면으로 이동하는 것을 확인하였다.
- 내용 확인 화면에서 '수정하기' 버튼을 눌렀을 때 운동 조건 선택 단계로 정상적으로 이동하는 것을 확인하였다.
- 운동 시간과 스트레칭 설정을 변경한 뒤 다시 내용 확인 화면으로 이동했을 때 수정된 내용이 정상적으로 반영되는 것을 확인하였다.

### 4. 재설정 기능 테스트
- 운동 계획 완료 후 '다시 설정하기' 버튼을 눌렀을 때 운동 목표가 초기화되는 것을 확인하였다.
- 운동 시간이 기본값인 30분으로 초기화되는 것을 확인하였다.
- 스트레칭 옵션이 해제되고 기본 선택 상태로 복원되는 것을 확인하였다.
- 운동 계획 설정 첫 단계로 이동하는 것을 확인하였다.
- BMI와 추천 BARRE 테마 정보는 유지된 상태로 운동 계획을 다시 설정할 수 있는 것을 확인하였다.
- 초기화 이후에도 새로운 운동 계획을 다시 생성할 수 있는 것을 확인하였다.

### 5. 화면 및 반응형(모바일) 테스트
- 데스크톱 화면에서 BMI 결과, 추천 테마, 운동 계획 요약 카드가 정상적으로 표시되는 것을 확인하였다.
- 모바일 화면(768px 이하)에서 상단 메뉴가 세로 방향으로 표시되는 것을 확인하였다.
- 모바일 화면에서 BMI 입력창이 한 열로 배치되는 것을 확인하였다.
- 모바일 화면에서 BARRE 테마 탭이 2열 레이아웃으로 변경되는 것을 확인하였다.
- 모바일 화면에서 운동 계획 요약 카드가 1열 구조로 표시되는 것을 확인하였다.
- 모바일 화면에서 입력창, 버튼, 카드가 화면 밖으로 벗어나지 않는 것을 확인하였다.
- 가로 스크롤 없이 정상적으로 사용할 수 있는 것을 확인하였다.
- 라이트 모드와 다크 모드에서 글자와 버튼이 정상적으로 표시되는 것을 확인하였다.

### 6. 입력 경험 테스트
- 운동 목표 입력 전 도움말과 0 / 30자 표시가 정상적으로 보이는 것을 확인하였다.
- 운동 목표를 입력할 때 글자 수가 실시간으로 반영되는 것을 확인하였다.
- 운동 목표를 2자 이상 입력했을 때 입력 조건 충족 상태가 표시되는 것을 확인하였다.
- 운동 목표를 비우거나 1자만 입력했을 때 오류 문구가 표시되는 것을 확인하였다.
- 오류가 발생한 뒤 조건에 맞게 수정했을 때 오류 상태가 해제되는 것을 확인하였다.

### 7. 조건부 입력 테스트
- 스트레칭 포함을 선택했을 때 스트레칭 시간 선택 영역이 표시되는 것을 확인하였다.
- 스트레칭 포함을 해제했을 때 스트레칭 시간 선택 영역이 숨겨지는 것을 확인하였다.
- 스트레칭 시간 선택 영역이 숨겨질 때 내부 입력 요소가 비활성화되는 것을 확인하였다.

### 8. 제출 상태 테스트
- 운동 계획 저장 버튼을 눌렀을 때 저장 중 상태 문구가 표시되는 것을 확인하였다.
- 저장 중에는 버튼이 비활성화되어 중복 제출이 방지되는 것을 확인하였다.
- 저장 성공 시 완료 메시지가 표시되는 것을 확인하였다.
- 저장 실패 시 오류 메시지가 표시되고 입력 내용이 유지되는 것을 확인하였다.
- 저장 실패 이후 다시 저장을 시도할 수 있는 것을 확인하였다.
