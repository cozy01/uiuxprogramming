# BARRE - 운동 계획 서비스

## 사용자와 목표
- 사용자: 바레 운동을 시작하고 자신에게 맞는 운동을 탐색하는 성인
- 목표: 키와 몸무게로 BMI를 확인하고, 추천 BARRE 테마를 이해한 뒤 운동 계획을 설정한다.
- 주요 행동: BMI 계산 및 BARRE 테마 추천 결과를 확인하고 운동 목표와 조건을 설정한다.

## 중간고사 신규 기능 (7주차 대비)
7주차에는 운동 목표와 조건을 입력하고 계획을 확인하는 기능을 구현하였다. 중간고사에서는 사용자가 자신의 신체 정보를 바탕으로 운동 테마를 추천받을 수 있도록 BMI 계산 및 BARRE 테마 추천 기능을 추가하고, 기존 운동 계획 설정 과정과 연결하였다.

- 키(cm)와 몸무게(kg)를 입력해 BMI를 계산한다.
- 입력값이 비어 있거나 범위를 벗어나면 오류를 안내한다.
- BMI 구간에 따라 BARRE 테마를 추천하고, 결과와 이유를 표시한다.
- MOVE / BALANCE / CORE / CARDIO / BURN / SLOW 소개 탭을 통해 테마별 설명을 비교한다.
- 추천 결과를 확인한 뒤 BMI와 추천 테마 정보를 유지하면서 기존 운동 계획 설정으로 이동한다.
- 다시 계산하기를 통해 입력과 결과를 초기화한다.
- 운동 시간과 스트레칭 시간을 비교하여 잘못된 설정은 오류를 안내한다.
- 운동 계획 완료 시 BMI, 추천 BARRE 테마, 운동 목표, 운동 시간, 스트레칭 정보를 최종 요약 카드로 표시한다.
- 계획 설정 완료 상태를 표시하고, 다시 설정하기를 통해 BMI와 추천 테마 정보는 유지하면서 운동 목표와 조건을 초기화할 수 있다.

## 기존 기능 (7주차)
- 개인정보 활용 동의 및 안내 팝업
- 운동 목표 입력과 빈 값 검사
- 운동 시간 및 스트레칭 선택
- 내용 확인, 수정, 완료, 다시 설정
- 화면 테마 전환, 회원 이름 글자 수, 서비스 기능 탭, 이메일 알림 신청

## 사용자 흐름
1. 개인정보 활용에 동의하고 '계획 설정 시작하기'를 누른다.
2. 개인정보 활용 안내를 확인한다. 취소 또는 Esc 시 동의가 해제된다.
3. 키와 몸무게를 입력하고 'BMI 계산하고 추천받기'를 누른다.
4. 잘못된 값은 같은 화면에서 오류를 확인하고 수정한다.
5. 올바른 값이면 BMI와 추천 BARRE 테마를 확인한다.
6. 여섯 가지 테마 소개 탭을 선택해 설명을 비교한다.
7. '추천 확인하고 계획 설정하기'를 눌러 BMI와 추천 테마 정보를 유지하면서 기존 운동 계획 설정을 진행한다.
8. 운동 목표, 운동 시간, 스트레칭을 설정하고 내용을 확인한다.
9. 운동 계획을 완료하면 BMI와 추천 테마를 포함한 최종 운동 계획 요약 카드를 확인한다.
10. '다시 설정하기'를 눌러 운동 계획을 다시 설정할 수 있다.

## 인터랙션 시나리오

### 1. 개인정보 활용 동의
- 사용자가 개인정보 활용 동의 체크박스를 선택하면 '계획 설정 시작하기' 버튼이 활성화된다.
- 버튼을 누르면 개인정보 활용 안내 팝업이 표시된다.
- '돌아가기' 또는 Esc를 누르면 팝업이 닫히고 개인정보 활용 동의가 해제된다.
- '동의하고 설정 시작하기'를 누르면 BMI 입력 화면으로 이동한다.

### 2. BMI 계산 및 BARRE 테마 추천
- 사용자가 키와 몸무게를 입력하고 'BMI 계산하고 추천받기' 버튼을 누르면 입력값을 검사한다.
- 입력값이 비어 있거나 지정된 범위를 벗어나면 오류 메시지를 표시하고 해당 입력창으로 이동한다.
- 올바른 값을 입력하면 BMI를 계산하고 BMI 구간에 따른 추천 BARRE 테마와 추천 이유를 표시한다.
- 추천된 테마가 자동으로 선택되며, MOVE / BALANCE / CORE / CARDIO / BURN / SLOW 탭을 눌러 각 테마의 운동 강도와 설명을 비교할 수 있다.
- '다시 계산하기'를 누르면 입력값과 계산 결과가 초기화된다.
- '추천 확인하고 계획 설정하기'를 누르면 BMI와 추천 테마 정보만 유지하고 운동 계획 설정 화면을 표시한다.

### 3. 운동 목표 및 조건 설정
- 사용자가 운동 목표를 입력하고 '운동 조건 선택하기' 버튼을 누르면 입력값을 검사한다.
- 운동 목표가 비어 있으면 오류 메시지를 표시하고 다음 단계로 이동하지 않는다.
- 운동 시간을 선택하면 선택한 시간이 실시간으로 표시된다.
- 스트레칭 포함 여부를 선택하면 스트레칭 시간을 설정할 수 있다.
- 스트레칭 시간이 총 운동 시간 이상이면 오류 메시지를 표시하고 다음 단계로 이동하지 않는다.
- '내용 확인하기'를 누르면 운동 목표, 운동 시간, 스트레칭 설정 내용을 표시한다.
- '수정하기'를 누르면 이전 단계로 돌아가 운동 조건을 변경할 수 있다.

### 4. 최종 운동 계획 확인
- 사용자가 입력한 내용을 확인하고 '설정 완료하기' 버튼을 누르면 최종 운동 계획 요약 카드를 표시한다.
- 최종 요약 카드에는 BMI, 추천 BARRE 테마, 운동 목표, 운동 시간, 스트레칭 정보가 표시된다.
- 계획 설정이 완료되면 진행 단계 대신 완료 상태를 표시한다.
- '다시 설정하기'를 누르면 운동 목표와 조건이 초기화되고 첫 번째 설정 단계로 돌아간다.
- BMI와 추천 BARRE 테마 정보는 유지하여 운동 계획을 다시 설정할 수 있다.

### 5. 기타 인터랙션
- 화면 테마 변경 버튼을 누르면 라이트 모드와 다크 모드가 전환된다.

## BMI 추천 규칙
- BMI < 18.5: SLOW
- 18.5 ≤ BMI < 23: CORE
- 23 ≤ BMI < 25: MOVE
- 25 ≤ BMI < 30: BALANCE
- BMI ≥ 30: SLOW

BMI는 참고 지표이며, BMI만으로 운동 능력이나 개인에게 적합한 운동 강도를 판단하지 않는다.

## 테스트 기록

### 1. 정상 경로
- BMI 23.9 계산 시 MOVE 테마가 추천되는 것을 확인하였다.
- BMI와 추천 테마 정보가 유지된 상태에서 운동 계획 설정 화면으로 이동하는 것을 확인하였다.
- 운동 목표 '체중감량', 운동 시간 30분, 스트레칭 10분을 설정한 뒤 최종 운동 계획 요약 카드에 입력 내용이 반영되는 것을 확인하였다.
- '다시 설정하기' 버튼을 누르면 운동 계획 설정 단계로 돌아가는 것을 확인하였다.

### 2. 오류 및 다른 경로
- 키 또는 몸무게를 입력하지 않았을 때 오류 메시지가 표시되는지 확인하였다.
- 키 또는 몸무게가 지정된 범위를 벗어났을 때 오류 메시지가 표시되는지 확인하였다.
- 잘못된 값을 수정한 뒤 정상적으로 BMI를 다시 계산할 수 있는지 확인하였다.
- 스트레칭 시간이 총 운동 시간 이상일 때 오류 메시지가 표시되고 다음 단계로 이동하지 않는지 확인하였다.
- 개인정보 활용 안내에서 '돌아가기' 또는 Esc를 눌렀을 때 동의가 해제되는지 확인하였다.

### 3. 화면 및 반응형
- 데스크톱 화면에서 BMI 결과, 추천 테마, 운동 계획 요약 카드가 정상적으로 표시되는 것을 확인하였다.
- 모바일 화면에서 입력창, 버튼, 결과 카드가 화면 밖으로 밀리거나 겹치지 않는지 확인하였다.
- 라이트 모드와 다크 모드에서 글자와 버튼이 정상적으로 표시되는지 확인하였다.
